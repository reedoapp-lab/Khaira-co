## 6. COLOR & STYLE REFERENCES

### Brand Color Palette (from CSS variables)
- **Primary**: #000000 (black) - for text, buttons, borders
- **Secondary**: #FFFFFF (white) - background, cards
- **Accent/Highlight**: Could incorporate subtle gold, rose gold, or soft pink accents
- **Status Colors**: 
  - Instock: #3ED660 (green)
  - Lowstock: #EE9441 (orange)
  - Outstock: #C8C8C8 (grey)

### Typography
- **Font**: Montserrat (all weights: 400, 500, 600, 700)
- **Header Style**: Uppercase, tracking/tight letter-spacing
- **Body**: Normal weight, line-height 1.4-1.6

### Visual Mood Board Keywords
- Elegant, comfortable, confident, invisible, premium, seamless, second-skin, everyday essentials, luxury, understated glamour

## 7. PHOTOGRAPHY SHOOT CHECKLIST

### Pre-Shoot Preparation
- [ ] Select 5-8 key products to feature
- [ ] Prepare 2-3 models (diverse skin tones, matching brand aesthetic)
- [ ] Style team: lingerie, props, accessories
- [ ] Photography equipment: 85mm or 50mm lens, tripod, reflectors
- [ ] Lighting setup: natural light preferred, or softbox studio lighting
- [ ] Background options: white, neutral grey, wood textures, black

### Shot List
- [ ] Hero banner - full body model in natural pose
- [ ] Product close-ups - fabric texture, detailing
- [ ] Product on model - Anti-Gravity Bra specifically
- [ ] Flat lay/flat lay - essentials arrangement
- [ ] Lifestyle - model at home, relaxing
- [ ] Under clothing - demonstration of invisibility
- [ ] Detail shots - waistband, stitching, finish quality

- [ ] Create thumbnail versions for collections

## 8. QUICK AI IMAGE GENERATION SETTINGS

### Midjourney Settings
- **Aspect Ratios**: 
  - Hero banners: --ar 16:9 or --ar 4:3
  - Square posts: --ar 1:1
  - Stories: --ar 9:16
  - Collection cards: --ar 4:5 or --ar 1:1
  
- **Style Parameters**:
  - `--style raw` for more realistic product photography
  - `--style artistic` for moodier, fashion-forward images
  - `--v 6.0` for latest version (best quality)

- **Quality Settings**:
  - `--stylize 250` (default good balance)
  - `--stylize 500` (more artistic)
  - `--stylize 1000` (very artistic, less product-accurate)

- **Control Parameters**:
  - `--cref` (character reference if using consistent model)
  - `--tref` (texture reference for fabric look)
  - `--cref` plus `--tref` for consistent brand aesthetic

### DALL-E 3 Tips
- Be specific about product details (seamless, ultra-soft, stretch fabric)
- Mention brand aesthetic (premium, elegant, invisible comfort)
- Specify lighting (soft natural, studio, dramatic)
- Include text elements in the prompt for on-image text
